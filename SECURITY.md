# Reporting security issues

This policy applies to the FootballerStats source repository and its distributed JavaScript and stylesheet copies.

## Reporting

Do not include passwords, tokens, cookies, private information or exploit details in a public issue.

If GitHub displays **Report a vulnerability** under this repository's Security tab, use that private reporting form:
https://github.com/nanahuatl/Wikipedia-FootballerStats-tool/security

Private vulnerability reporting may not yet be enabled. If the form is unavailable, open an issue titled **Request for a private security reporting channel**, without technical vulnerability details, and ask the maintainer to establish a private channel before sharing them.

Once a private channel is available, include the affected version or commit, wiki, reproduction steps, expected and actual behavior, and potential impact. Use test accounts and non-sensitive example data.

## Scope and updates

Security reports should identify the exact installed copy; manually installed Wikipedia pages do not automatically follow GitHub updates. Fixes will be documented in the change history when available. No guaranteed response time is promised.

For ordinary bugs, use [GitHub Issues](https://github.com/nanahuatl/Wikipedia-FootballerStats-tool/issues).
